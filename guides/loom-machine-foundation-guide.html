Loom Machine Foundation Guide: From Machine Drawing to Installation

A loom machine foundation is only as good as the machine information behind it. We set out each block from the supplier drawing, build it to the approved design, coordinate anchors and grout pockets with the surrounding floor, and check levels before installation. We do not assume loads, vibration values or tolerances.

Start With The Machine Drawing

The foundation follows the machine, not the other way round. At Prachi Construction Projects, we ask for the supplier layout, support points, anchor details and any installation notes before we set out a block. If the machine is not finalised, we mark the outstanding information rather than inventing it. Load, vibration and tolerance values are [CONFIRM WITH OWNER / STRUCTURAL ENGINEER].

For airjet and waterjet looms, the difference between two models can change the support pattern and the service route. Our airjet sheds and waterjet sheds pages show how the rest of the building is shaped by those choices. This guide stays focused on the block itself.

Information we ask the owner to collect

  • Machine layout with support and anchor positions.
  • Approved structural drawing for the block and surrounding floor.
  • Service routes that must stop at or pass near the block.
  • Written confirmation of any value marked for confirmation.

A useful habit is to label every incoming document with the date it was received and the machine it refers to. On a unit with several models, drawings can look similar while differing at the anchor points. We have found that a simple register prevents a crew from setting out the right block from the wrong revision.

If the supplier changes a support position after concrete is placed, the block may need to be revisited. We tell owners that early, because it affects both programme and cost. The decision to proceed or pause belongs to the owner, and we record it in writing before work continues.

Setting Out And Levels Come First

Setting out is where most foundation errors begin. We transfer the grid to the site, mark each block position and check the level reference before excavation. The owner should know which drawing is current, because a revised row spacing can move several blocks at once. All positions and levels are [CONFIRM WITH OWNER / STRUCTURAL ENGINEER] until the approved drawing is issued.

We also look at the relationship between the block and the finished floor. If the surrounding floor is raised later, a block that seemed correct in isolation can end up too low or too high. That is why we review the floor build-up with the foundation, not after it.

A simple site discipline

Before concrete, walk the marked positions with the machine representative where possible. A short check at this stage is far easier than breaking a block after it has hardened.

Setting out is also a communication exercise. We explain the reference line to the site team and to the owner so everyone uses the same starting point. When a later trade measures from a different wall or boundary, errors appear across a whole row. One agreed reference keeps the work consistent.

Block, Reinforcement, Anchors And Grout

The block is built to the approved design. Reinforcement, anchor pockets and grout arrangements are coordinated with the supplier drawing, and any change is recorded. Reinforcement details and material basis are [CONFIRM WITH OWNER / STRUCTURAL ENGINEER]. We do not describe a block as suitable for a machine until the responsible designer and supplier inputs agree.

Anchor accuracy matters because the installation crew works to those points. We protect pockets during concreting and keep them accessible. Where a sleeve or embedded item is needed, we confirm its position with the service drawing so nobody has to cut the block later.

Our machine foundation construction service sets out the scope we handle. The cost page explains why a foundation estimate depends on drawings and site conditions instead of a generic figure.

During concreting, we protect pockets and embedded items from accidental filling or movement. A pocket that is crushed by a tool may still look acceptable on the surface but cause trouble during installation. We check them again after the pour, not only before it.

Material choices for the block and grout should match the approved design. If an owner wants to substitute a product to manage availability, we ask for confirmation from the designer first. The substitution record then sits with the foundation drawings so the installation team knows what was actually built.

Tie The Foundation Into The Surrounding Floor

A foundation does not sit in an empty room. The floor around it has to meet the block neatly, carry operator movement and respect drain or service routes. We coordinate the floor finish, joints and edges with the block so there is no avoidable step or gap at the machine interface.

In a waterjet shed, this also means keeping floor falls and collection channels away from a dry machine point unless the design requires otherwise. In an airjet shed, it means keeping working aisles and cleaning routes consistent across rows. The finish and joint arrangement are [CONFIRM WITH OWNER / STRUCTURAL ENGINEER].

What we look for on a walk-through

  • Block edges that meet the finished floor cleanly.
  • Pockets and sleeves that remain open and usable.
  • Aisles that do not change level at the machine line.
  • Drain routes that do not cross an anchor zone.

The floor around a block should be finished so an operator can walk and clean without catching an edge. We look at the junction from the user point of view, not only from a structural drawing. A neat junction is also easier to maintain when the machine is eventually serviced or replaced.

Checks Before Machine Installation

Before handover, we check the marked positions, levels and pockets against the current drawing and record any deviation. The machine supplier should be present for the final interface check where possible. Acceptance values, including tolerance, are [CONFIRM WITH OWNER / STRUCTURAL ENGINEER]. We prefer a written record to a verbal assurance.

If installation is phased, we agree which blocks are released first and how the remaining area will be protected. That keeps installation work from damaging fresh finishes and avoids a later contractor working without the original setting-out record.

We prefer to hand over a short written record with the setting-out reference, any deviations and the items still pending. The machine supplier can then install with context instead of guessing what happened on site. That record becomes useful again if a later machine is added to the same row.

Common Mistakes We Try To Prevent

The most common problem is starting from an old machine layout. The next is treating the block separately from the floor and services. We also watch for anchors set before the supplier confirms the final drawing, and for a finish that makes a previously correct level look wrong.

None of these are dramatic failures; they are coordination gaps. A clear drawing set, a short hold point before concrete and a final walk-through solve most of them. For a wider unit plan, see gala unit construction or our gala build guide. Call +91 76004 90851 to discuss a machine layout.

Another avoidable problem is allowing another trade to cut a fresh block for a late service route. We ask for all service drawings before concrete and keep a hold point for any penetration. A small approved sleeve in the right place is far better than a hurried cut after the foundation has cured.
